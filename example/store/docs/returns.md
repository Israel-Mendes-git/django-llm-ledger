# Returns and refunds

## Return window
You can return unopened bags of coffee within 30 days of delivery for a full refund. Opened bags can be returned within 14 days only if the coffee arrived damaged or was the wrong item.

## How to start a return
Write to help@serraverde.example with your order number and a photo of the package. We reply within one business day with a prepaid return label.

## Refund timing
Refunds go back to the original payment method within 5 business days after we receive the package. Pix refunds are usually instant.

## Equipment returns
Grinders and brewers can be returned within 30 days if unused and in the original box. Used equipment is covered by the warranty instead.
